# User Stories
## Basic Task Organizing
As a **Basic User** I would like to be able to view and mark tasks assigned to me as completed.</br>
As an **Elevated User** I would like to be able to assign tasks to basic users for them to complete.</br>
## Announcements/News Feed
As a **Basic User**, I want to view company and department announcements so that I can quickly see what requires my attention.</br>
As an **Elevated User**, I want to publish announcements so that I can communicate relevant information.</br>
## Hierarchical User Permissions
As a **Basic User** I want to be able to request additional permissions.</br>
As an **Elevated User** I would like to be able to assign the applications that a basic user is permitted to utilize for their work.</br>
As an **Administrator** I want to be able to dynamically configure permissions and titles to appropriately assign workplace resources.</br>
## Centrally Organize Apps
As a **Basic User**, I want to view applications assigned to me so that I can quickly access the tools required for my work.</br>
As a **Basic User**, I want to browse applications available to my organization so that I can discover tools that may be useful to me and request access to them.</br>
As a **Basic User**, I want to view the status of my application requests so that I know whether they have been approved or denied.</br>
As an **Administrator**, I want to register applications in HUBStack so that they can be assigned or requested by users.</br>
## Admin Console/Dashboard
As an **Administrator** I want to be able to easily configure settings in relation to HUBStack from an easy to utilize dashboard.</br>
## Access company Drive
As a **Basic User**, I want to access organizational documents and resources so that commonly needed information is available from one location.</br>
## Digital App Helpdesk/FAQ/Instructions For App Use
As **any User** I want to be able to use the integrated helpdesk within HUBStack in order to find out how HUBStack works and where to find features.</br>
## Employee Directory
As **any User** I want to be able to search the employee directory to find out company information on co-workers like contact details and department.</br>
## Company Calendar Integration
As **any User** I would like to be able to view the company calendar in order to see upcoming and important events related to the company.</br>
## User Data Tracking
As an **Administrator** I would like to be able to view data in relation to HUBStack utilization.</br>
