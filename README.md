### Idea #1 - Internal tool for managing company applications
A company application hub written in C# with an easy to utilize ui system like Avalonia or WPF(Windows Presentation Foundation) that acts as a centralized location for company news and events and also organizes applications utilized by the company. Can be offline or online depending on company requirements (ie. secure networks requiring offline, or a company wanting online integrations like hooking into a company social media)

This can be built upon with many additional features like:
- Restricted mode, allowing only for company approved applications to be run
- Various web-based integrations for company website inclusion
- IT support tools
- Data collection for company utilization like application usage time
- Company tools like timesheet tracking and clocking in and out
